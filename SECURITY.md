# Security

Please report vulnerabilities privately, not in a public issue: use **Report a
vulnerability** on the repository's Security tab (GitHub private vulnerability
reporting). Include what's affected (server, client or app, and the version) and how to
reproduce it. You'll get a reply as soon as possible, and a fix will be released before
the details are made public.

Lemon Wire's security model and its limits (what an index admin, other members and
the network can see) are described in the README's
[Security notes](README.md#security-notes) and in [docs/SPEC.md](docs/SPEC.md) §6.

Releases are signed: check downloads as described in
[Verifying a download](README.md#verifying-a-download).
